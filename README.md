# SQL Business Case Portfolio

## Overview

This repository contains **100 real-world SQL business questions** designed to simulate common business scenarios faced by Data Analysts and Business Intelligence professionals.

The project covers various analytical domains including sales, customers, products, employees, operations, business intelligence, and advanced SQL analytics.

Each query is written using Microsoft SQL Server and focuses on solving practical business problems through SQL.

---

## Objectives

- Practice SQL using real business scenarios
- Improve analytical and problem-solving skills
- Demonstrate SQL techniques commonly used in industry
- Build a professional Data Analyst portfolio
